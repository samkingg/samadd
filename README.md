# الكلمات المتقاطعة العربية - Arabic Crossword Game

A beautiful and intelligent Arabic crossword game for Android, featuring AI-generated questions and elegant Material Design 3 UI.

## ✨ Features

- **🤖 AI-Powered Content**: Dynamic question generation using artificial intelligence
- **🎨 Elegant Design**: Beautiful Material Design 3 UI with Arabic-inspired colors
- **📱 RTL Support**: Full right-to-left layout support for Arabic text
- **🎯 Multiple Difficulty Levels**: Easy, Medium, Hard, and Expert modes
- **🎮 Interactive Gameplay**: Touch-friendly crossword grid with smooth animations
- **💡 Smart Hints**: Intelligent hint system to help players
- **📊 Scoring System**: Points-based scoring with hint penalties
- **🌙 Dark Mode**: Automatic dark/light theme support

## 🏗️ Architecture

This app follows modern Android development best practices:

- **MVVM Architecture** with ViewModels and StateFlow
- **Jetpack Compose** for modern UI development
- **Hilt** for dependency injection
- **Material Design 3** for consistent theming
- **Navigation Component** for screen navigation
- **Coroutines** for asynchronous operations

## 🎯 Difficulty Levels

1. **سهل (Easy)**: 8 words - Perfect for beginners
2. **متوسط (Medium)**: 12 words - Moderate challenge
3. **صعب (Hard)**: 15 words - For experts
4. **خبير (Expert)**: 18 words - Ultimate challenge

## 🚀 Getting Started

1. Clone the repository
2. Open in Android Studio
3. Sync Gradle files
4. Run on device or emulator

### Prerequisites

- Android Studio Hedgehog or later
- Android SDK 34
- Kotlin 1.9.22 or later

## 🎮 How to Play

1. Select your preferred difficulty level
2. Tap on a cell in the crossword grid
3. Read the clues in the side panel
4. Enter Arabic letters to fill the words
5. Use hints when you're stuck
6. Complete the puzzle to see your score!
