# لعبة الكلمات المتقاطعة العربية - Arabic Crossword Game

## نظرة عامة - Overview

لعبة كلمات متقاطعة جميلة ومتطورة للأندرويد، مصممة خصيصاً للغة العربية مع دعم الذكاء الاصطناعي لتحديث الأسئلة والتلميحات.

A beautiful and advanced crossword game for Android, specifically designed for the Arabic language with artificial intelligence support for updating questions and hints.

## المميزات الرئيسية - Key Features

### 🎮 اللعبة - Game
- **واجهة عربية جميلة** - Beautiful Arabic interface
- **مستويات متعددة** - Multiple levels
- **نظام نقاط متطور** - Advanced scoring system
- **تلميحات ذكية** - Smart hints system
- **حفظ تلقائي** - Auto-save functionality

### 🤖 الذكاء الاصطناعي - Artificial Intelligence
- **توليد أسئلة ذكي** - Smart question generation
- **تحديث تلقائي للمحتوى** - Automatic content updates
- **تلميحات مخصصة** - Personalized hints
- **صعوبة ديناميكية** - Dynamic difficulty

### 🎨 التصميم - Design
- **ألوان عربية أصيلة** - Authentic Arabic colors
- **خطوط عربية جميلة** - Beautiful Arabic fonts
- **واجهة مستخدم حديثة** - Modern user interface
- **دعم الوضع المظلم** - Dark mode support

### ⚙️ الإعدادات - Settings
- **مستويات صعوبة متعددة** - Multiple difficulty levels
- **إعدادات صوت واهتزاز** - Sound and vibration settings
- **خيارات الخط** - Font options
- **إدارة البيانات** - Data management

## التقنيات المستخدمة - Technologies Used

- **Kotlin** - لغة البرمجة الرئيسية
- **Android Jetpack** - للواجهات والمكونات
- **MVVM Architecture** - نمط التصميم
- **Room Database** - قاعدة البيانات المحلية
- **Retrofit** - للاتصال بالشبكة
- **Coroutines** - للعمليات غير المتزامنة
- **ViewBinding** - لربط الواجهات

## متطلبات النظام - System Requirements

- **Android API Level**: 21+ (Android 5.0+)
- **Minimum RAM**: 2GB
- **Storage**: 50MB free space
- **Internet**: Required for AI features

## التثبيت - Installation

### للمطورين - For Developers

1. **استنساخ المشروع** - Clone the repository:
```bash
git clone https://github.com/yourusername/arabic-crossword-game.git
```

2. **فتح المشروع** - Open in Android Studio

3. **تثبيت التبعيات** - Install dependencies:
```bash
./gradlew build
```

4. **تشغيل التطبيق** - Run the app

### للمستخدمين - For Users

1. **تحميل APK** - Download APK from releases
2. **تفعيل المصادر المجهولة** - Enable unknown sources
3. **تثبيت التطبيق** - Install the app

## كيفية اللعب - How to Play

1. **اختر مستوى الصعوبة** - Choose difficulty level
2. **اقرأ التلميحات** - Read the clues
3. **اكتب الكلمات** - Type the words
4. **استخدم التلميحات** - Use hints when needed
5. **اكمل المستوى** - Complete the level
